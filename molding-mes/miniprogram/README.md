# 微信小程序端（只读看板）

原生微信小程序（WXML/WXSS/JS，无构建步骤），用微信开发者工具直接打开本目录即可。

## 绑定到现有小程序

1. 打开本目录 `project.config.json`，把 `"appid": "touristappid"` 改成**你现有小程序的 AppID**
   （或在开发者工具「详情 → 基本信息 → AppID」里直接改成自己的 AppID）。
2. 服务端 `server/.env` 填入同一小程序的凭证：
   ```
   WX_APPID=wxXXXXXXXXXXXXXXXX
   WX_SECRET=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   WX_DEV_MODE=false
   ```
   重启服务端生效。凭证只在服务端使用，不会入库、不会下发到小程序。
3. 微信公众平台 → 开发管理 → 开发设置 → **服务器域名** → request 合法域名，
   添加你的 HTTPS 域名（小程序只调用 `/api/mp/*` 与 `/api/admin/*`，无需配其他域名）。
4. 确认小程序已开通「手机号快速验证」组件权限（2023 年起需付费，未开通可改用管理员预录手机号 + 开发模式）。

## 权限是怎么判定的

小程序每次登录都要过四道关，缺一不可：

| 关卡 | 判定依据 | 不通过时的提示 |
| --- | --- | --- |
| 微信身份 | `jscode2session` 换 openid | — |
| 是在职员工 | `users` 表存在该手机号且 `ACTIVE` | 该手机号尚未获得授权，请联系管理员录入 |
| 小程序白名单 | `wx_access(tenant_id, phone)` 存在且 `enabled=1` | 尚未开通小程序访问权 |
| 可见视图 | `wx_access.views` 覆盖优先，否则角色默认 | 没有该视图的查看权限 |

公司管理员在管理后台「小程序授权」页按手机号开通，并可逐人勾选可见范围。
取消授权会同时置空已绑定的微信身份，避免"取消后还能看"。

## 角色与默认可见范围

| 角色 | 默认可见 | 说明 |
| --- | --- | --- |
| 老板 BOSS | 库存总览、生产实况 | 成品/原料/标签库存与预警、在制订单与机台实况 |
| PMC | 排产计划 | 任务时间轴、机台负载、换模与配料时点、交期风险 |
| 技术员 TECHNICIAN | 设备与模具 | 机台状态、待维护模具、保养进度、下次换模时间与模具编号 |
| 生产人员 PRODUCTION | 当班任务、生产实况 | 未绑定机台时看全部，绑定后只看本机台 |
| 仓库 WAREHOUSE | 库存总览、配料计划 | — |
| 配料员 MIXER | 配料计划 | 原料用量、使用时间、混料机 |
| 业务员 SALES | 订单 | — |
| 公司管理员 ADMIN | 全部 | — |

## 本地联调（没有 AppID 凭证时）

服务端 `.env` 设 `WX_DEV_MODE=true`（默认开启，且仅在非 production 生效），
小程序登录页会变成手机号输入框，跳过微信鉴权直接登录。
开发者工具里把服务器地址设为 `http://127.0.0.1:8080`，并在「详情 → 本地设置」勾选**不校验合法域名**。

## 数据严谨性约定

- 小程序**只读**，报工与出库仍走安卓 APP，避免双写冲突。
- 模具保养只给「剩余模次 / 已用百分比」这类确定量；只有存在最近排产效率时才推算到期天数，并标注依据，没有依据就不给日期。
- 换模时间由开工时间反推（换模工时 + 30 分钟缓冲），与排产引擎口径一致，页面上写明推导方式。
