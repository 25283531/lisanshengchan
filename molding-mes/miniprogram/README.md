# 微信小程序端（只读看板）

原生微信小程序（WXML/WXSS/JS，无构建步骤），用微信开发者工具直接打开本目录即可。

## 绑定到现有小程序

本项目已绑定到 AppID **`wx8be948bf11ef3fca`**（`project.config.json` 已改好）。
服务端凭证放在 `server/.env`（不入库、不下发到小程序）：

```
WX_APPID=wx8be948bf11ef3fca
WX_SECRET=（填你自己的，已在本机 .env 中）
WX_DEV_MODE=false        # 上线必须 false
WX_BIND_MODE=auto        # auto=绑定码；phone=手机号组件（需企业认证）
```

还需要完成的配置：

1. 微信公众平台 → 开发管理 → 开发设置 → **服务器域名** → request 合法域名，
   添加你的 **已备案 HTTPS 域名**（小程序只调用 `/api/mp/*`，无需配其他域名）。
2. 公众平台 → 设置 → 基本设置 → 配置《用户隐私保护指引》。

> ⚠️ **个人主体小程序的限制**：该 AppID 主体类型为「个人」（`principal_type:0`）。
> 个人主体**无法使用 `getPhoneNumber` 手机号快速验证组件**——该能力仅对已微信认证的非个人
> 主体小程序开放，且按次收费。因此本项目默认走「管理员生成绑定码」的方式，
> 与主体类型无关，任何小程序都能用。

## 员工怎么完成绑定

```
管理员：后台「小程序授权」页 → 选中已开通的员工 → 生成绑定码（6 位，30 分钟有效）
员工  ：小程序首登 → 输入手机号 + 绑定码 → 绑定成功
```

也可以把 `MPBIND:XXXXXX` 做成二维码让员工扫（小程序「扫码」按钮支持解析 `MPBIND:XXX`
或 `...?c=XXX` 两种格式）。

绑定码是一次性的：用过作废、可提前作废、手机号不匹配会拒绝、过期自动失效。
生成前会校验该手机号**既是本公司员工、又已在小程序白名单里**，两头缺一头都发不出码。

## 权限是怎么判定的

小程序每次登录都要过四道关，缺一不可：

| 关卡 | 判定依据 | 不通过时的提示 |
| --- | --- | --- |
| 微信身份 | `jscode2session` 换 openid | — |
| 是在职员工 | `users` 表存在该手机号且 `ACTIVE` | 该手机号尚未获得授权，请联系管理员录入 |
| 小程序白名单 | `wx_access(tenant_id, phone)` 存在且 `enabled=1` | 尚未开通小程序访问权 |
| 可见视图 | `wx_access.views` 覆盖优先，否则角色默认 | 没有该视图的查看权限 |

公司管理员在管理后台「小程序授权」页按手机号开通，并可逐人勾选可见范围。
取消授权会同时置空已绑定的微信身份，避免"取消后还能看"。

## 本地联调（不想动真机时）

服务端 `.env` 设 `WX_DEV_MODE=true`（仅在非 production 生效），此时前端用 **`dev-` 开头的假 code**
可命中本地桩跳过微信鉴权；登录页仍会走真实的 wx.login，但不会被微信拒绝。

配了这个开关不影响真实用户：微信真实 code 形如 `0b3xxx`，永远不会落到 dev 分支，
所以真实凭证填了之后 dev 模式可以一直留着，不会误伤线上登录。

开发者工具里把服务器地址设为 `http://127.0.0.1:8080`，并在「详情 → 本地设置」勾选**不校验合法域名**。

## 数据严谨性约定

- 小程序**只读**，报工与出库仍走安卓 APP，避免双写冲突。
- 模具保养只给「剩余模次 / 已用百分比」这类确定量；只有存在最近排产效率时才推算到期天数，并标注依据，没有依据就不给日期。
- 换模时间由开工时间反推（换模工时 + 30 分钟缓冲），与排产引擎口径一致，页面上写明推导方式。
